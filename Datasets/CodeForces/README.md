# CodeForces

CodeForces-Submissions is a programming submission dataset released in 2025 by the open-r1 team of Hugging Face, derived from the world-renowned competitive programming platform Codeforces. The dataset aggregates real user code submissions from 8 sources, including Kaggle, Hugging Face, GitHub, and custom crawls, spanning nearly 15 years of data from 2010 to 2025. Each record contains fields such as submission ID, source code, the contest and problem it belongs to, programming language, judging verdict, number of tests passed, runtime, and memory consumption. The dataset is split into three subsets according to judging results: default (all submissions), selected_accepted (submissions that are executable and pass all public tests), and selected_incorrect (incorrect submissions that pass at least one public test). The dataset is released under the CC-BY-4.0 license and is mainly used to train and evaluate models' code reasoning ability.
