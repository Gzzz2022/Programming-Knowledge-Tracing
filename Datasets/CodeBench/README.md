# CodeBench

CodeBench is an online judge programming platform developed by the Institute of Computing (IComp) at the Federal University of Amazonas (UFAM), Brazil. It automatically records all actions performed by students on the embedded IDE while they attempt to solve assigned exercises. This dataset records the complete operation logs of CS1 course students solving programming exercises on the embedded IDE from 2016 to 2024, covering multiple academic years and semesters. The data is collected automatically and contains the code submitted by each student together with immediate pass/fail feedback, which can be used to analyze programming learning behavior and the evolution of students' coding process.
