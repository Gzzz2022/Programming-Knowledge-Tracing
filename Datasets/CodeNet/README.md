# CodeNet

CodeNet is a large-scale, multi-language dataset of programming submissions containing 13,916,868 submissions from the AIZU and AtCoder online judge platforms, covering 4,053 programming problems and 55 programming languages (95% of which are concentrated in C++, Python, Java, C, Ruby, and C#). Each submission corresponds to a source code file and is accompanied by detailed metadata, such as user, language, submission time, judge status, CPU time, memory, and code size. The data is organized hierarchically by problem ID and language, with metadata provided separately in CSV format. Problem and user IDs are anonymized. The dataset is suitable for research on source code classification, program repair, code generation, and learning analytics.
